# 111 工具链生产与验收

以 tools/dev/toolchain-lock.json 为现有版本约束。777 共享组件固定来源 SHA、Actions 产物 ID 和 SHA-256；111 独有工具链由 dev-toolchain.yml 在变更或手动触发时生产，不新增定时任务。

- 共享组件：`python3 tools/dev/ai-toolchain.py shared-install --artifacts-dir ./toolchain-downloads --download`，需要已经授权 GitHub CLI。
- 111 独立组件：由相同运行下载组件及 manifest-pin，使用 `python3 tools/dev/component-bundle.py install <component> <bundle-dir> <install-root> --manifest-sha <已核验的manifest SHA-256>`。组件按摘要隔离，逐片校验，拒绝越界链接和污染目录；安装产物不覆盖系统 SDK。
- Android 组件分别生成 JDK、Android SDK/NDK、Gradle Wrapper 和 Maven 缓存；在隔离网络的新安装目录运行实际 debug、androidTest、release、Lint 和单测。Gradle 基线候选需审查后提交。
- Rust 组件包含固定 1.99.1 和 Android 两 ABI 标准库、Cargo 源与 Git 依赖缓存；独立离线验证 fetch。V8 仍由现有精确指纹的独立生产和验证流程负责。
- 777 移动端准备脚本固定复制自 15437765368eecfbdbee7d9e372a74195efff0e4。ARM64 使用固定归档中的已签名 Termux 包，按原版本检查；x86 需要对应已签名、同版本的独立缓存。
- 此次生产链不等于完整 APK 运行时替换或设备验收。移动端产物还须接入 APK 装配及运行时命令映射，真实设备执行和签名发布仍按 AGENTS.md 门禁执行。
