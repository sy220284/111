# 国内模型接入实现与验收边界

本分支采用官方国内 Responses 入口，避免对原生协议执行无必要的转换。DeepSeek、Kimi 首先复用核心的账号级目录刷新链路，将公开模型列表与已核实的模型能力档案取交集。GLM、MiniMax、千问只预置候选，不能冒充已验证的在线目录。

- DeepSeek: https://api-docs.deepseek.com/zh-cn/guides/responses_api/ 和 https://api-docs.deepseek.com/zh-cn/api/list-models/
- GLM: https://open.bigmodel.cn/ ，Coding Plan 资格和适用端点以账号合同为准。
- MiniMax: https://platform.minimax.cn/ ，国内 Codex 接入使用 api.minimax.cn。
- Kimi: https://platform.moonshot.cn/ ，国内开放平台 api.moonshot.cn。
- 千问: https://help.aliyun.com/zh/model-studio/base-url 与 https://help.aliyun.com/zh/model-studio/compatibility-with-openai-responses-api

核心档案中 context 是客户端预算上限；未核实型号使用保守 32768，不声称是厂商最大容量。未来要核实推理档位、视觉、工具、压缩和原始推理保留。保留 OpenAI 原有认证和目录逻辑。

待验收：安全凭据接入、全部账号目录（千问原生分页、GLM 套餐及 MiniMax 官方目录）、动态模型注册和未知模型能力验证、协议转换及连续任务、Android 真机。此分支不得视为完整交付或合并候选。

## Android 凭据通道（待真机验收）

预置服务商可直接填写 API Key。AES-GCM 和 Android Keystore 加密记录置于 noBackupFilesDir；配置只引用保留标识。核心启动时通过专用 stdin 前置帧读取密钥，不通过环境变量、命令行参数或普通 RPC 传递密钥值。Rust 仅在配置与预置端点严格匹配时使用密钥，国内 HTTP 请求禁用重定向。修改或撤销本机凭据需要用户显式重启核心，遵循已有任务保护。仍需独立真机安全与备份回归，未证明所有运行时路径。
