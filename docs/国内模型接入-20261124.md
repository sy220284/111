## 安全凭据与目录

AES-GCM/Android Keystore 加密记录保存在 noBackupFilesDir；启动前置帧提供密钥及严格绑定的端点，普通 RPC 与配置只传引用。Qwen 北京空间仅允许单一 DNS 标签和指定官方域名路径，切换空间必须输入匹配密钥；原固定端点旧记录只用于原地址，旧凭据撤销后先关闭旧核心。禁用国内接口重定向。分页必须完整且总量、页号和模型 ID 一致，不发布部分目录。

模型与服务商成对保存。新会话明确发送服务商 ID，历史会话回读归属，提交任务前核对模型。切换默认服务商清除旧模型、思考档位与服务等级配置。显示实时目录错误，未知模型不自动继承 GPT 能力。

## 真实模型验证

设置中的模型目录提供单模型验证入口。用户确认计费后调用 111 扩展 RPC `modelProvider/model/verify`；先查实时账号目录，再通过核心已存在的 Responses 客户端发起最多两轮固定测试请求。检验实际函数名称、JSON 参数、调用 ID、结果回传、流式文本及结束事件；使用两个独立随机挑战，第二个仅出现在本机生成的函数结果内。只在两轮模型身份一致且完整通过时，按端点/凭据摘要将模型加入当前进程可选目录。请求失败、断流、身份不明或切换密钥不会放行未知模型。新增模型限保守文本预算，其他能力保持未确认；目录声明、真实验证、真实项目长任务三者分别留证。验证本身不上传对话、文件、密钥或执行真实工具；密钥仅作为独立服务商 HTTP 认证。用户未明确确认前不发送计费推理请求。
