# 国内模型接入实现与验收边界

本分支采用官方国内 Responses 入口，避免对原生协议执行无必要的转换。DeepSeek、MiniMax、Kimi 开放平台复用核心账号目录刷新链路：已知 Responses 能力模型进入选择列表，新增未知 ID 进入隐藏检查目录。GLM、千问、Kimi Code 订阅提供本机密钥加载后的文档候选目录，不能冒充账号实时授权。

- DeepSeek: https://api-docs.deepseek.com/zh-cn/guides/responses_api/ 和 https://api-docs.deepseek.com/zh-cn/api/list-models/
- GLM: https://open.bigmodel.cn/ ，Coding Plan 资格和适用端点以账号合同为准。
- MiniMax: https://platform.minimax.cn/ ，国内 Codex 接入使用 api.minimax.cn。
- Kimi: https://platform.moonshot.cn/ ，国内开放平台 api.moonshot.cn，Kimi Code 国内订阅使用 https://api.kimi.com/coding/v1，凭据单独保存。
- 千问: https://help.aliyun.com/zh/model-studio/base-url 与 https://help.aliyun.com/zh/model-studio/compatibility-with-openai-responses-api

核心档案中 context 是客户端预算上限；未核实型号使用保守 32768，不声称是厂商最大容量。未来要核实推理档位、视觉、工具、压缩和原始推理保留。保留 OpenAI 原有认证和目录逻辑。

待验收：安全凭据真机回归、全部账号目录（千问工作空间原生分页、GLM 套餐及 Kimi Code 订阅目录）、动态模型注册和未知模型能力验证、协议转换及连续任务、Android 真机。此分支不得视为完整交付或合并候选。

## Android 凭据通道（待真机验收）

预置服务商可直接填写 API Key。AES-GCM 和 Android Keystore 加密记录置于 noBackupFilesDir；配置只引用保留标识。核心启动时通过专用 stdin 前置帧读取密钥，不通过环境变量、命令行参数或普通 RPC 传递密钥值。Rust 仅在配置与预置端点严格匹配时使用密钥，国内 HTTP 请求禁用重定向。修改或撤销本机凭据经用户确认后由独立控制器独占空闲核心，核对配置回读与凭据加载；撤销先终止旧核心再移除密钥。单个密钥损坏按服务商报告。仍需独立真机安全与备份回归，未证明所有运行时路径。

核心对国内预置限制 GPT 专属远端压缩、托管搜索、图像生成和未核实视觉能力；静态候选仅在本机凭据存在时进入模型选择。DeepSeek、MiniMax、Kimi 列表去除 Codex 专用 client_version 参数，并保留 HTTP 鉴权失败状态以失效缓存。尚未支持全部新模型的自动能力核验。

## 复查后的模型选择与目录回执

- 新会话明确发送服务商 ID；历史会话回读所属服务商；目录按服务商隔离，提交任务前核对模型归属。切换默认服务商清除旧模型、思考档位和服务等级配置。
- 已配置的国内服务商可从设置进入目录检查。对于公开列表接口，`model/list` 带 `modelProvider` 和 `includeHidden=true` 时强制刷新，失败返回明确错误；未知 ID 不进入正常选择器。DeepSeek 结合已知能力档案处理实时 context、输入模态及推理档位，避免把模型目录读取成功当作任务验收成功。
- CI 已发现并修复共享目录稀疏检出缺失、ViewModel 行数超限两项问题。最终通过情况以当前 HEAD 的实际工作流为准。
