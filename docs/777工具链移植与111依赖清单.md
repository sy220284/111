# 777 工具链移植与 111 依赖清单

审计基线：111 `51e4a2de9c9c91b8d75ee622dde6d5098e07e45b`；777 `15437765368eecfbdbee7d9e372a74195efff0e4`，已成功的工具链运行 [44730301955](https://github.com/sy220284/777/actions/runs/44730301955)。

## 代码及版本来源

全树 11513 个受 Git 跟踪的文件；上游 Rust Cargo.lock 1509 个锁定包记录。完整版本台账见 [toolchain-dependency-inventory.json](toolchain-dependency-inventory.json)，包含全部发现的 Cargo/uv/pnpm 锁文件、Gradle 直接声明、Action 固定引用和清单 Git blob SHA。Gradle 传递依赖以真实构建生成的 lockfile 和 verification-metadata 为准，当前缺失时明确阻断，不生成伪锁。

## 迁移原则

- 777 原有 Linux/WSL x64 组件（Node 24.22.3、actionlint 1.7.12、ARM64 runtime-cache）按不可变 artifact ID 与 GitHub SHA-256 验证后按需安装。新入口提供 plan/bootstrap/check/run/gradle。每个组件独立目录，仅在子进程 PATH 中优先使用，不污染系统。
- 111 的 JDK 17、Gradle 8.11.1、AGP 8.9.2、Kotlin 2.1.20、SDK 35、NDK 27.2.12479018、Rust 1.99.1、LLVM 21、V8 152.2.0 保留项目兼容基线。777 的 JDK 27/Gradle 9.8.1/AGP 9.4.0/SDK 37/JVM 21 与 111 现有构建契约不等价；不能直接替换。111 的 Android 17 设备矩阵明确要求 37.2，777 的 37.0 镜像不能作为对应验收镜像。
- 777 手机 ARM64 缓存已实际下载核对：Git 2.56.1（包 SHA-256 与 111 现有 Git 锁一致）、curl 8.23.0、jq 1.8.2、ripgrep 15.2.0、Python 3.14.10、pip 26.3-1、Node 26.13.1、npm 11.6.2。缓存无 x86_64 包，不把 ARM64 产物冒充双架构完成。当前 111 手机端的 DSH/VSCodroid/curl 装配路径保持，需在双架构真实构建及设备验收通过后才能切换。

## 使用

```sh
bash tools/dev/ai-toolchain.sh plan
bash tools/dev/ai-toolchain.sh bootstrap --artifacts-dir /path/to/downloads
bash tools/dev/ai-toolchain.sh check
bash tools/dev/ai-toolchain.sh run -- node --version
bash tools/dev/ai-toolchain.sh run -- actionlint -version
bash tools/dev/ai-toolchain.sh gradle :app:testDebugUnitTest
```

下载必须使用 toolchain-lock.json 中的固定 GitHub artifact ID，保留原始 ZIP（名称使用 artifactName.zip 或 777-组件名.zip）。过期产物必须重新审核并更新锁，不能自动信任同名 latest。手机运行时安装和项目 Gradle 锁仍需独立验收。
