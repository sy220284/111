# 111 Android · 参考截图布局与交互契约（2026-11-22）

参考用户提供的五张 ChatGPT 安卓端截图，保留以下设计：顶部「聊天 / 工作」分段切换、左上侧栏、右上快速新建、抽屉功能列表与可独立滚动的会话历史、底部固定操作，以及珊瑚色主操作与悬浮圆角输入框。

## 原生功能映射

「聊天」对应实际任务对话 `chat`，「工作」对应原工作总览 `home`；项目文件、会话历史、待审批为常驻侧栏入口，终端、代码差异、审查、技能、插件、MCP 收入「查看更多」。完整功能仍在原有路由和设置中；每条会话点击使用真实 threadId，服务端成功恢复后才切换页面。未接入的语音输入功能不制作虚假按钮。

## 组件及交互

- 顶栏高 72dp，中部 196×49dp 双态切换；左右为不小于 48dp 的点击区；其他详情页仍显示返回按钮和具体页面标题。
- 侧栏固定功能区、独立滚动历史区和底部新建/设置/账号/连接状态，手机使用抽屉，宽屏使用常驻侧栏，无底部导航。
- 会话同步单次上限由 30 扩至 100；侧栏取消只显示六条的限制，仍可过滤当前已载入的会话；「查看全部会话」进入历史资料库与服务端检索。
- 输入区使用 28dp 圆角，左侧实际「添加附件」入口，右侧 50dp 珊瑚色圆形发送按钮；执行中仍支持停止、补充指令，连接状态与模型方式继续使用现有控制行。
- 新会话空态隐藏重复的任务标题行。继续保留图像附件的真实导入与清理、运行中操作安全规则、键盘适配、TalkBack 标注和减少动效。

## 颜色、字体、尺寸

背景 #FFFFFF；主字 #263139；辅助文字 #56646D；线条 #D8DEE1；分段器底 #F0F0F0；主强调色 #FF806F；抽屉宽最大 318dp。实际 Android 字体、文本缩放及 360/393/411dp 响应式规则遵循 Compose 代码。
