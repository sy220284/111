状态：方案待实现、待设计及设备验收；本文件为执行索引，不新增第三份权威规范。基线 main b6134d7e，开放 PR #100 3af3a094e、#101 526a43be、#102 45e647c2、#103 efc1a24a。实施前重读当前 HEAD、AGENTS.md、接口协议动作清单与落地验收台账、ui_surface_policy.json，保留原有协议、审批、工作区、草稿、运行隔离和全部可用功能。

## 1. 四项技能与设计定位
实际读取技能目录 2026-11-20 四份 ZIP：finesse-brief 0.5.0（system-domain、grammar、handoff、day-two、workbench-types）；finesse-ui 0.22.0（product-ui、ai-console、h5-mobile、interaction-motion、component-scope、preflight）；frame-smith 0.1.0（motion-floor、beat-structure、reveals、anti-cheap-motion）；finesse-term 0.3.0（可观察行为、语义一致与移动端成对约束）。采用原生 Compose 实现，不引入网页或视频渲染依赖。
设计读法：product + 手机 app shell + AI console，SOUL 6 / SPECTACLE 3 / DENSITY 6（建议初值；阅读与对话降低密度，专业诊断按需增加）。保留典雅白/墨色/珊瑚及深色主题。页面以当前任务为中心、可展开执行依据，常驻停止，主要操作在拇指可达区；一级内容清爽，二级专业信息可核验。素材仅使用已登记的实际文件、图片、图标及空状态资源，不额外生成装饰图。
两类风险：过度统一造成所有页面同构；增加动效造成延迟或干扰阅读。解决：同一基础组件按业务形成不同布局骨架，所有动效跟随真实动作和状态，手势可中断。

## 2. 工作台对象、导航与无表单
主对象为会话内的任务/执行回合；会话持有历史与草稿，项目持有工作区，执行环境是任务的实际运行位置，模型、技能、插件、MCP 是依赖，审批与产物归属相应任务。任务状态由真实 core 事件写入；用户仅提供意图、授权、选择和必要文字；系统推导名称、配置默认值及读取结果。外部能力由真实连接回执决定。首次打开可直接描述任务；缺少登录、存储授权等前置条件时仅展示实际缺项。
保持顶部导航 + 抽屉侧栏，不新增底栏或平板/横屏。顶栏显示当前对象；侧栏按真实会话与项目管理，进行中/待处理标识及快捷过滤；聊天首页上方在有活跃任务时显示薄任务条，主区域按时间顺序展示执行，底部输入区和停止保持稳定；历史/队列/产物通过原有入口展开。
交互决策顺序：系统推导 > 单击选项 > 原生选择器/已有授权 > 智能体独立任务交接 > 必要单项文本意图。只有密钥直接进入配置输入；正常对话、搜索、文件编辑、命令、语音文字与协议确需的用户回答保留自身功能语义。禁止用连续单项回复弹窗代替配置表单。必要非配置文本（会话重命名等）使用单层轻量编辑或智能体意图，不重复确认同一值。风险写入、删除、密钥撤销、权限审批仍保留原确认与回执。
智能体交接携带结构化对象标识、工作区、所需权限、目标与验收条件；独立待确认任务草稿，不拼接用户未发送原任务、不擅自切走运行中会话、不自动发送、不改审批。明确显示目标对象与预览，用户确认后使用现有任务链路；保存后按原协议回读。无真实支持的动作保持实际限制并提供可行入口。#103 现有 ActionReplyRow 不应成为默认替换所有字段的唯一组件。

## 4. 视觉与组件系统
复用 VisualSystem.kt、docs/ui-assets/tokens.json 的 111-visual-v8；典雅白基线保持，提议将纯白与浅灰之间的层级微调为暖中性（需先做 Figma/原生对比与对比度验证；不擅自覆盖现有 token）。主动作墨色实心、次动作中性描边、危险最终确认红、珊瑚用于活动、翡翠用于有效成功。颜色与图标/文字共同传达状态。建议基础网格 4/8dp，页面边距 16/20dp、组间 20/24dp、行内 8/12dp；继续沿用 13/16/24dp 圆角和 18/24dp 图标、48dp 触区。正文建议 14–16sp，标题 20–24sp，次要文字 12–13sp，数据数字等宽；实际与既有排版 token 对齐，200% 字号自动增高和滚动。减少无功能边框与重复卡片；阅读区不套多层卡；弹层才使用有层级的阴影。
组件家族与代码归属：
- 基础操作：CodexControlPrimitives.kt（主/次/文字/图标/危险按钮、按压、焦点、真实禁用、忙碌宽度稳定）。
- 选择：AtlasInteractionComponents / AtlasChoiceRow / AtlasCompactChoice（选中、取消、搜索、不可选原因、无障碍语义）；复杂数值用预设+连续调整+精确能力，避免步进造成大量点击。
- 容器：现有 CodexDetailSheet、CodexActionSheet、CodexConfirmDialog、CodexFloatingMenu，定义菜单/半屏/全屏/危险确认边界；一个操作一层容器，返回收起最前层，禁止滚动穿透。
- 任务状态：ChatTimelineComponents、RuntimeStatusPresentation、SessionTaskControls、ConversationControlBar；统一 queued/thinking/tool/streaming/awaiting-input/succeeded/failed/stopped/partial 九种视觉语义（仅由实际证据映射，未提供的部分完成/恢复/重试能力不得伪造）。
- 授权与配置：ActionReply.kt、EcosystemScreens、EngineSettingUi、ExecutionEnvironmentPage；替换无意义回复弹窗；通过预设、原生选择、自动推导、独立任务交接。
- 产物：AttachmentPreviewDialog、FullTextReaderDialog、WorkspaceFileEditor、DiffReaderPage；加载时预留宽高比，长内容单层阅读与定位。
- 环境：#101 的 DeveloperToolStatus / DeveloperRuntime；核心启动与可选开发工具独立，工具状态分安装/执行/联网/依赖可用，真实原因、修复和重试；保留明确发布门禁。
- 回执：AtlasOperationProgress、ProtocolFeedback、AtlasUpdateStatus、CodexRecoveryState；未知进度只显示实际阶段/不定进度，成功以回读确认。失败优先给恢复动作，原始诊断可展开。
每个组件登记默认、按压、焦点、选中（适用）、禁用、加载、空、错误、成功及恢复（适用），同时覆盖亮/暗、长文案、200% 字号、TalkBack；有键盘的设备保留焦点，原生触控不照搬网页 hover。Figma 使用变量、Auto Layout、变体与实例，长文字自适应；所有业务画面引用同一组件库，不逐张复刻固定坐标 SVG。保留单一设计生成源作为离线交接，最终以真实 Compose 状态和截图校验。

## 5. 动效：事件驱动、可中断、连续反馈
基础时长沿用当前 motionMs：100/140/180/200/240/280/220/450/320ms，减弱动效自定义过渡 0ms。新增按场景的 motion token 和中断策略，不复制页面内私有时钟。使用 Compose 的 transition/animate*AsState、AnimatedVisibility、Animatable、Lazy 列表动画、系统 Drawer/Sheet 与原有 CodexMotion。手势期间 1:1 跟随，释放后按位移或速度决策，取消恢复前态；同一控件反复触发从当前位置连续过渡。所有业务状态由真实回执推进；动效不会阻止停止、审批、切换、返回和发送。frame-smith 的节拍用于“确认动作—状态变化—终态落定”，不把视频时间线当作业务时钟。

| 动效场景 | 设计及实现建议 | 验收 |
|---|---|---|
| 按钮/图标 | 100ms 按压、140ms 释放，微缩放至 0.98，色彩轻变；明确焦点 | 触区稳定，重复点击不重复 RPC |
| 单选/开关 | 180ms 勾选、指示器位移、状态文字过渡 | 回读前 pending，失败恢复 |
| 菜单 | 200ms 锚点展开/收拢 | 返回与外部点击关闭 |
| 页面 | 280ms 新页轻入场；返回时保留位置及上下文 | 不闪白、无双页面可交互 |
| 侧栏 | 跟手右滑/关闭；释放弹簧收敛，建议 240–320ms 参考 | 轴锁、冲突、快速反转、系统返回 |
| 底部弹层 | 320ms 原生开闭；拖动跟手、锚点明确 | 背景锁滚动、IME 和系统安全区 |
| 列表增删/排序 | 180–240ms 局部位移，稳定 key；拖拽跟手与取消 | 不跳滚动、不误重排 |
| 多任务 | 180ms 状态转换、薄任务条增减；真实队列更新 | 不切错会话，不改变其他任务 |
| 时间线 | 240ms 执行证据展开；文本批量按帧追加 | 滚离底部不自动抢回，停止位置固定 |
| 思考/工具调用 | 低幅活动指示，建议 1200ms 周期；仅真实活动状态运行 | 结束/离屏/减弱动效停止循环 |
| 待审批/回答 | 180–240ms 入场强调、动作稳定，不反复闪烁 | 真实 request ID 归属，拒绝/取消可达 |
| 错误/恢复 | 180ms 状态替换、240ms 原因展开；重试后真实阶段变化 | 无伪进度，无重复提交 |
| 成功 | 450ms 图标收敛；成功后动作可直接使用 | 写入及回读完成才触发，不阻塞 |
| 预览/图片 | 220ms 离散缩放；手势跟随、双击复位 | 原图长宽比、关闭还原来源 |
| 文件/终端 | 文件列表局部更新，终端输出即时追加 | 光标、滚动和命令输入稳定 |
| 主题 | 建议 180–240ms 色彩自然过渡，保持文本对比 | 200% 字号与减弱动画同步 |
| 工具检查/更新 | 真实步骤和已知百分比变化，未知显示阶段 | 连接失败可修复，后台不阻塞 |
| 全局动效 | 统一时长、缓动和 spring，避免大范围重复淡入、无意义弹跳 | 60Hz/120Hz 按设备实际刷新；以实测帧时间判定 |

动效目标：以 60Hz 参考帧预算 16.7ms（高刷按实际刷新率调整），验收记录 FrameTiming/Perfetto 或等效测量的 P95 帧时间、掉帧比例和卡顿；比较同一设备旧版和新版，目标关键交互不退化，长任务流式输出期间停止仍可立即响应。动画录屏、起始/中间/终态截图与真实事件时间戳同时登记。系统动画缩放 0 时结果、焦点、无障碍与返回路径等价。以上指标为待验收目标。
