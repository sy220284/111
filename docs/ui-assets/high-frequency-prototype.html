01 / 运行中的模型切换

点击输入栏模型，选择下一轮模型，确认当前任务仍在执行。

02 / 草稿与排队

输入文字后，分别尝试引导、排队、停止；任务配置中创建独立草稿，再切回普通草稿。

03 / 直接操作

打开侧栏处理待审批任务，打开设置验证服务地址，尝试选择式问答及新建文件。

验收宽度 360 / 393 / 411；深浅色、200% 字号、减少动效。颜色、圆角和动画时长来自仓库设计令牌。此原型用于设计评审，不替代 Android 真机及接口验收。
