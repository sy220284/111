# 高频操作交互原型（2026-11-25）

打开 [high-frequency-prototype.html](high-frequency-prototype.html) 的本地文件即可操作；不需要安装依赖或连接后端。

- 基于 tokens.json 的既有设计令牌，支持深浅色、360/393/411 宽度、200% 字号和减少动效。
- 可操作场景：模型与思考强度同面板选择、运行时下一轮模型、固定停止位置、引导、排队、配置任务草稿隔离、待处理入口、低频会话管理、地址原位编辑及校验、问答推进、文件与终端入口。
- 原有图集保留作为历史页面覆盖证据；上述交互以本原型和 PR #103 的实际代码为新基线。其他页面继续使用统一组件规范，需在 Android 真机回归验收。
- 原型使用示例数据和模拟回执，无真实网络调用。Figma Starter 工具额度不足，未同步在线文件；本原型不充当 Figma 或真机验收证据。
