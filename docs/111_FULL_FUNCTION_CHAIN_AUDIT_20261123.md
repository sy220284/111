## 三、本轮确认且已编码的共同根因：全局安全操作只检查当前会话

**复现条件：** 会话 A 运行、切到空闲会话 B（或新建空会话），`vm.running=false`，但 `threadExecutions` 中仍有 A 的在途任务。原代码中的 `LocalDataTransferCard`、`ConnectionRestartController` / 诊断页面只检查前台 `running`，安装更新根本未检查任务全局状态。备份可能获得不一致的数据快照，重启与安装会中断后台任务。

**统一方案：**

1. `GlobalWorkSnapshot` 对全部在途会话、首回合创建、终端、待审批、当前可见任务、本机备份/恢复建立单一判断；`GlobalWorkUi` 使所有关联按钮同步更新。
2. `LocalDataTransferCard` 在导出、导入、系统选择器回调以及用户最终确认时检查真实状态，锁定危险操作；同时避免正在备份时新的会话发送/终端执行破坏快照。
3. `ConnectionRestartController` 在入口和关闭核心前各检查一次；`EngineDiagnosticsPage` 使用相同禁用条件和提示。
4. `AppUpdateManager.install` 在开始校验和交给系统安装器前两次检查，仍在运行时保留已验证 APK 并明确告知。安装包校验真正失败则保持错误状态。
5. `CodexApplication` 空闲资源释放同样由共享状态控制，防止页面后台时数据传输与内核进程操作并发。

**回归证据设计：** `GlobalWorkSnapshotTest` 覆盖六个状态源与跨会话并行；`ConnectionRestartPolicyTest` 覆盖隐藏任务/首回合/终端/审批；`UiNavigationInstrumentedTest.offscreenRunningTaskBlocksLocalDataTransferButtons` 在 Android 35 三种宽度构造“当前会话空闲、其他线程运行”，验收备份与恢复均禁用并留下专门截图。代码不改变 Rust DTO、UI 的原业务入口和未发送草稿。

## 四、明确仍缺少的真实回执

- `UiProtocolMatrix` 是**方法归属目录**。目前各业务方法的 20 组 Kotlin 请求线缆样例用于字段级校验，尚不能等价为 187 个真实服务端请求或 8 类 Host 请求的逐项端到端通过。
- 可见动作的正常/失败/取消、网络断开、跨会话后重试及真实写入回读须按“按钮→请求→响应→重新读取→恢复”留单独证据。对长任务尤其核实背景进程、终端与状态重建。
- 锁定的 Host 8 类中已有 3 类能力采取明确受控不支持路径，后续须依真实宿主权限、参数及安全评估验收，不能通过在 UI 增加按钮代替后台实现。
- 外部账号、MCP OAuth、真实插件源、远程执行环境、真机 ARM64、安卓厂商文件选择器和正式签名安装需要专门实测；三档 Android 35 x86_64 的截图和固定协议形状数据仅用于界面/交互证据。
- PR #68（键盘真输入法与系统级截图）、#69（权限档位与回读）、#70（MCP 授权）为并行待合并链路；最终重验以各自最新 SHA 为准，避免共享文件旧版覆盖。

## 六、跨页面延伸：终端在后台的实际运行保护

原终端命令会在 VM 的协程中执行等待 RPC，但启动时未调用 Android 前台服务；已有通知服务仅依据前台会话与审批判断保活/重连，终端退后台可失去进程保护。复核后将终端放入与回合任务同一前台服务的工作状态，后台独立终端也能维持通知；通知文本和停止动作根据当前任务类型选择正确行为。新增 `ForegroundTaskPolicyTest` 对终端单独运行和断连重连的正反例，UI 及真实后台进程存活须分别验证。保留独立终端进程 ID、`command/exec/*` 协议和原有输出日志流，避免将终端错误地合并到当前聊天的运行态。


## 七、跨所有页面的数据归档独占与在途请求核对

在 29 项功能逐项复盘中，原有数据归档只禁用了备份页按钮和新消息/终端提交，仍有工作区文件编辑、配置写入、扩展安装等来自其他页面的本机操作。全局维护状态现额外计入所有在途 RPC、账号登录和方案提交，禁止在未完成写操作时开始备份；已开始数据传输时顶层独占进度弹层遮蔽所有一级/二级/三级交互，并在 ViewModel 通用 RPC 写入口再次进行状态校验。归档结束后原有页面保持；设备回归验证弹层的出现及消失。

全量审计器原先计算了文档声明但没有被截图采集器登记的名称 `missing_screens`，却没有使 CI 失败，现将缺失截图列为实质阻断并加入负向测试。两项变更均为共享机制，后续页面无需逐个复制拦截逻辑。
