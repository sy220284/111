## 设备验收清单

1. ARM64 Android 10–17（不同 API/SELinux 版本）安装 APK，检查核心可执行、STDIO 协议初始化。
2. 登录 ChatGPT、读取真实模型，检查账号切换和重启后的本地凭据。
3. 创建和恢复线程；文本输入、流式回复、终止与失败消息均可到达。
4. 导入 ZIP 工程，执行只读命令，修改文件，核查差异和写入内容。
5. 触发命令、文件、权限请求，分别确认接受/拒绝，检查后台任务状态。
6. 验证深色面板对比、侧边栏与键盘避让、至少 360dp 宽度布局，宽屏常驻抽屉。
7. 对照 `app-server-protocol` 中实际 DTO，逐条核验请求参数、枚举、错误回包与事件负载。
