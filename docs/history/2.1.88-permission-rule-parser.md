## 版本差异与保护原则

1. 2.1.310 将 `KillBash` 映射至 `TaskStop`，并新增 MCP 资源名称迁移，不覆盖这份新版映射表。
2. 旧版 `BashOutputTool` / `AgentOutputTool` 已非新版同一等价别名，**不把 2.1.88 整份映射表复制回来**。
3. 2.1.310 在基础 Tool(content) 解析之外还有 `X9` 畸形格式分类、MCP 禁止括号通配符和其它安全提示；仅恢复符号职责和可读性，不弱化这些校验。
4. 原短符号继续保留，并同时导出具名接口，现有 2.1.310 调用点无需迁移即可运行。
5. `tests/historical-permission-rule-parity.test.cjs` 使用 **2.1.310 原函数体** 执行 2.1.88 已知输入行为，验证特殊字符、奇偶反斜杠、弃用别名及新版额外保护。
