# 111 全量移动界面视觉重构设计与验收

基线：2026-11-25，main 9732f04d；正式版 v0.1.0-111.47（ca930694）。
本次按手机原生任务效率、原创视觉导演、可访问性与界面设计系统交叉审查。设计目标是「墨色工作台」：任务正文占据主视觉，暖铜强调操作上下文，珊瑚标记活动变化，状态使用原有语义色；专业编辑内容保持克制、清晰、有节奏。所有页面复用同一 Ink 主题，不创建第二套主题，不改变业务协议和权限。

## 一、结构与视觉决策

| 区域 | 视觉与交互规范 | 当前代码落地 |
| --- | --- | --- |
| 页面壳 | 标题与说明入口同一行，正文从首项有效内容开始；长标题允许自然适配 | AppNavigation / SectionIntro 注册说明，消除独立说明图标行 |
| 内容容器 | 16dp 页面基准，弱分隔线组织普通项目，复杂表单与风险操作维持独立表面 | MaterialPanel 弱化描边；保持现有屏幕间距策略 |
| 会话工作台 | 正文优先，附件、模型、发送、权限、方式与更多配置形成单一输入组件；运行与停止操作保持固定位置 | ConversationComposer 将次级操作收进输入表面，保留原 IME 与发送回调 |
| 会话侧栏 | 保留项目上下文、会话连续列表、置顶优先及用户主动打开的检索；选中、未读及运行状态明确可辨 | SidebarSessionRow 选中色、标题层级、大字号自动两行 |
| 设置 | 明确分组、轻分隔线，账号与运行状态作为概览，复杂更新与备份保持业务区域 | SettingsHub 普通分组移除边框并添加组内分隔 |
| 选择与操作 | 普通选择使用清晰选中状态、48dp 以上触区；轻量上下文菜单弱化容器边框；风险动作保留明确文字及颜色 | AtlasChoiceRow、CodexDetailSheet |
| 状态 | 色点+标签双重表达；断连恢复区缩小装饰并保留原因与下一步；有效空结果单独呈现 | StatusPill、CodexRecoveryState |
| 任务目标 | 多段编辑采用全屏空间，内容可滚动、保存操作固定，避免二次系统安全区压缩 | ThreadGoalSheet 全屏容器 |
| 专业阅读 | 文件、差异、终端保持内容优先，等宽字体、行号、增删状态、复制及定位 | DiffReaderPage 行文字提升一档；终端、文件操作仍待单独实景审查 |
| 动效 | 现有 CodexMotion 的按压、选择、进入、状态变化与减少动效统一；不驱动整个 IME 容器动画 | 复用当前按压、Crossfade、颜色过渡；仍需实测首帧与退出 |

## 三、验收闭环

- 代码检查覆盖 255 个生产 Kotlin 文件；共享组件调用 506 处；32 个功能入口、36 个子页面静态检查，无错误。全功能源级映射 32/32、官方方法 198。
- 插件主页截图采集改为已安装目录；插件发现截图保留独立发现页。历史过渡重复截图改录额度编辑面板；采集器为所有当前配置计算 SHA-256 并在 manifest 记录重复内容组，便于持续排查。哈希相同只能证明内容重复，不能自动认定业务场景错误。
- 保留现有 Android 设备配置及完整用例，增加页面说明入口与目标编辑按钮断言。验证正常连接、断连、权限、键盘、大字号、深浅色和实际动效须有独立设备证据。
- 本工作区下载并核验正式版 APK 的发布 SHA-256；环境缺少 ADB、Android SDK 与模拟器，无法实际安装。Figma 目标文件读取返回 Starter 限额。因此尚无最新源码编译、设备截图、真实账号、动效及在线 Figma 回读证据。后续必须以同一候选 SHA 的 CI 与真实设备结果逐项复核；上述 85 项是设计目标，不能把静态覆盖当成全量视觉改版通过。
