# 111 原版移动界面体验优化与验收

基线：2026-11-25，main 9732f04d；正式版 v0.1.0-111.47（ca930694）。
本次以原有正式版 v0.1.0-111.47 的视觉体系与操作结构为准。取消墨色工作台及其后讨论的替代设计；沿用既有双主题、色彩、圆角、边框、状态标签、设置分组及输入区结构。优化目标为可读性、布局适应性、交互效率、可靠性及动效质量，保留现有业务协议与权限。

## 三、验收闭环

- 代码检查覆盖 255 个生产 Kotlin 文件；共享组件调用 506 处；32 个功能入口、36 个子页面静态检查，无错误。全功能源级映射 32/32、官方方法 198。
- 插件主页截图采集改为已安装目录；插件发现截图保留独立发现页。历史过渡重复截图改录额度编辑面板；采集器为所有当前配置计算 SHA-256 并在 manifest 记录重复内容组，便于持续排查。哈希相同只能证明内容重复，不能自动认定业务场景错误。
- 保留现有 Android 设备配置及完整用例，增加页面说明入口与目标编辑按钮断言。验证正常连接、断连、权限、键盘、大字号、深浅色和实际动效须有独立设备证据。
- 本工作区下载并核验正式版 APK 的发布 SHA-256；环境缺少 ADB、Android SDK 与模拟器，无法实际安装。Figma 目标文件读取返回 Starter 限额。因此尚无最新源码编译、设备截图、真实账号、动效及在线 Figma 回读证据。后续必须以同一候选 SHA 的 CI 与真实设备结果逐项复核；上述 85 项是原版体验验收目标，不能把静态覆盖当成全量视觉改版通过。
