# 111 Android · 参考截图布局与交互契约（2026-11-22）

参考用户提供的五张 ChatGPT 安卓端截图，保留以下设计：顶部「聊天 / 工作」分段切换、左上侧栏、右上快速新建、抽屉功能列表与可独立滚动的会话历史、底部固定操作，以及珊瑚色主操作与悬浮圆角输入框。

## 原生功能映射

「聊天」对应实际任务对话 `chat`，「工作」对应原工作总览 `home`；项目文件、会话历史、待审批为常驻侧栏入口，终端、代码差异、审查、技能、插件、MCP 收入「查看更多」。完整功能仍在原有路由和设置中；每条会话点击使用真实 threadId，服务端成功恢复后才切换页面。未接入的语音输入功能不制作虚假按钮。

## 组件及交互

- 顶栏高 72dp，中部 196×49dp 双态切换；左右为不小于 48dp 的点击区；其他详情页仍显示返回按钮和具体页面标题。
- 侧栏固定功能区、独立滚动历史区和底部新建/设置/账号/连接状态，所有手机宽度均使用抽屉侧栏，无业务底部导航；宽屏常驻侧栏为废弃历史布局。
- 会话同步单次上限由 30 扩至 100；侧栏取消只显示六条的限制，仍可过滤当前已载入的会话；「查看全部会话」进入历史资料库与服务端检索。
- 输入区使用 28dp 圆角，左侧实际「添加附件」入口，右侧 50dp 珊瑚色圆形发送按钮；执行中仍支持停止、补充指令，连接状态与模型方式继续使用现有控制行。
- 新会话空态隐藏重复的任务标题行。继续保留图像附件的真实导入与清理、运行中操作安全规则、键盘适配、TalkBack 标注和减少动效。

## 颜色、字体、尺寸

背景 #FFFFFF；主字 #263139；辅助文字 #56646D；线条 #D8DEE1；分段器底 #F0F0F0；交互强调色 #C8483E（确保白色按钮文字可读），辅助暖珊瑚 #FF806F；抽屉宽最大 318dp。实际 Android 字体、文本缩放及 360/393/411dp 响应式规则遵循 Compose 代码。

## 四技能交叉审计与当前真实链路

- UI 设计技能：全局文字层次、低对比边框、空态减噪、一体式输入、分区侧栏、48dp 触控区和主色对比度统一；复杂业务页面统一复用共享控件。
- 工作台架构师：聊天/工作双入口、固定常用功能、次要功能折叠、历史会话独立按需渲染；保留真正的项目、审批、终端、代码审查、插件、模型与连接路径。
- 视频审美动效技能：只提取「状态变化有原因、时间统一、动作反馈可复核」的方法；原生采用 Compose 轻量点击/展开/切换，不嵌入视频渲染或无业务价值的动态特效。
- 术语技能：界面动作使用「聊天、工作、历史会话、添加附件、重试发送、重新连接」等后果清楚的中文；协议字段保留在专业配置及执行依据中。

会话恢复：旧会话保持可追溯 ID，恢复时用骨架提示并延长读取/恢复超时到 120 秒；切回应用检查断线并恢复选中会话。长任务：应用持有会话，用户启动任务时以前台服务提供运行通知和入口，停止/完成后结束常驻服务。输入：文字草稿保留本机；发送失败移除准确的临时消息、显示可操作的重试；三张以内照片通过安卓系统选择器导入，多图出现个别失败时保留已导入结果。设置：普通文字值可直接填写，数字/开关选择输入类型，JSON 收到高级选项。
