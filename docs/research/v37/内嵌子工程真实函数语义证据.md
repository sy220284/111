固定依据：v37 导出工作流采用的 Git 提交 `3c64d1669174e825fb0fbae088c5ec95edaa7339`，可直接读取每份历史 Blob 与当前文件的字节比较。本轮未取得研究包 `.tar.zst` 原件，不能声称该包已校验。

真正覆盖的**另一套代码**：
- `src/plugin-testing-kit/`：294 份完整独立插件测试框架代码，包含收集器、断言/循环比较、Mock、宿主加载、插件测试执行及失败回收。

`scripts/audit-v37-supplemental.cjs` 对 318 份文件核实当前 Git Blob 与固定 v37 Blob；对真实 JS/TS/TSX/MJS 做 AST 解析；对插件测试框架和状态库构建独立模块/函数调用候选图；对手工建立的函数语义记录进行**真实函数定义 + 定向测试文件存在性**验证。行为测试另由 `tests/v37-supplemental-runtime.test.cjs` 实际执行，覆盖循环结构相等、Map/Set、Mock Store/Session、atom、derive/read、乐观更新 CAS 重试和 64 次封顶。

旧版子工程源码已存在且逐字节一致时不重复添加、不强行混入主模块。可复现命令：

```bash
npm run check:v37-supplemental
# 需要完整本地 Git 历史，CI fetch-depth: 0
npm run audit:v37-supplemental
```
