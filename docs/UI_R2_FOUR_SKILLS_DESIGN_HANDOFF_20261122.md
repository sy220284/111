## 信息结构：保持桌面 Codex 的工作模型

1. 顶栏：一行页面身份和最必要的全局操作。差异查看固定归属任务工具，避免顶栏与时间线双入口重复。
2. 侧栏：新建、当前任务、历史、工作区、必要的工具及设置；活动任务与待审批固定在历史列表上方，不随记录滚走。
3. 主阅读区：每个会话的真实步骤、操作依据、审批、错误与可恢复路径。阅读历史时保留滚动位置；新内容以计数浮层提示。
4. 底部输入：模型/协作方式、附件、文字、发送/补充/停止；键盘展开时仍可用。小屏优先保持输入区与快捷任务的可达性。
5. 批量管理：进入选择模式后切换视觉状态，操作前展示确切数量；归档与永久删除分别表达可恢复性、风险和反馈。
6. 设置与诊断：普通设置以人能理解的名称和表单呈现；RPC/JSON/路径进入明确的高级或诊断层。
