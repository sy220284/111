# 111 全局 UI 无配置表单改造

基线：main b6134d7e。范围为全部手机功能入口、原生运行工作流与子页面。本次不引入平板、企业或新的实验入口；不修改既有接口权限、协议字段、密钥保护与最终确认。

## 统一交互

用户先选择需要完成的动作。可推导的信息直接从当前工作目录、实际连接地址、服务商预置或已读取的对象获取。固定项用选择、开关或数值控件；任意文本只在独立的动作回复窗口出现，一次回答一个问题，关闭保留原值。复杂配置和文件整理可交给实际任务会话，准备草稿后用户主动发送。

| 模块 | 原表单改造 | 保留的实际功能与验证 |
|---|---|---|
| 模型服务商 | 官方预置直接显示服务商与固定地址，仅密钥仍原生输入；千问业务空间单项回复；自定义服务商从有效地址产生名称，其他选项按需打开 | ProvidersPage、DomesticProviderController、原配置写入和真实目录/验证；地址与密钥环境变量引用校验 |
| 运行环境 | 本机或远程设备选择；一个连接地址回复自动生成名称，可选单独改名 | environment/add/info/status 原接口与 WebSocket 地址校验；不自动连接 |
| 高级配置 | 原键名、数值、JSON 组合表单退役，改为真实 Codex 对话草稿 | ConfigPage、CodexViewModel.prepareAgentAction、原常用配置写入回读；复杂变更由用户确认后执行 |
| 全局工作偏好 | 一键添加已支持模板、可单独回复内容、交给 Codex 整理 | EngineSettingEditor、原生 verified config write/read；人工发送 |
| 数值和运行设置 | 选择、开关、百分比滑块、常用数值预设及步进；特殊数值单项回复 | EngineSettings.parse 与原回读校验范围 |
| 文件管理 | 新建默认名称；创建类型选择、重命名和复制时单独回复；复杂整理转入实际对话 | WorkspaceFileActions、系统导入与文件编辑；原覆盖冲突、删除确认、目录边界 |
| 项目 | 当前文件夹直接登记，默认目录名；关联会话仍为明确选择；重命名单独回复 | project/create/import/update，与当前目录及会话归属 |
| 会话与分组 | 重命名/新建分组由单独回复；其余选择和直接操作 | thread/name/set、threadSection/create/update、原批量整理 |
| 任务目标 | 目标单项回复，状态选择，额度预设或单项回复；确认保存 | thread/goal/get/set/clear、原目标及额度类型约束 |
| 队列 | 添加与修改任务文本为独立动作回复；拖动排序与停止保持 | thread/queue/add/update/reorder/delete/start；草稿按会话保存 |
| 代码审查 | 默认范围选择，指定补充范围只在所选操作中回复 | review/start、原确认及当前会话 |
| 终端 | 终端尺寸步进或常用尺寸预设；命令与当前运行中的标准输入照常 | command/exec/resize、原命令输入及运行反馈 |
| 关联资料 | 回复备注内容自动生成建议名称，可选单独改名 | thread/attachment/add/list/remove，原身份键和确认 |
| 插件共享 | 真实本机目录选择、共享信息回复、成员类型和角色选择、名单增删 | 原插件共享接口，实际发布前确认，访问范围及对象变更保持明确确认 |
| 动态请求 | 逐个问题与选项，上一条/下一条，必要密钥遮蔽；明确确认提交 | item/tool/requestUserInput、MCP elicitation 原响应契约；必答、拒绝和取消仍有效 |
| 正常输入 | 任务、搜索、文件编辑、终端、实时语音文字保持原生交互 | 这些输入直接承载用户内容，不属于配置表单 |
| 其他模块 | 沿用已有原生选择、状态和操作组件 | 账号、用量、技能、应用、MCP 只读目录、主题、备份、更新等无新增表单 |

## 组件与验收

统一入口：ActionReply.kt；本地数据和协议实现仍由各所属业务模块持有。正常回复窗口不通过普通任务发送，既有任务办理状态和确认回调保持。智能体交接入口仅准备实际任务草稿，不自动执行、不请求密钥、不改变审批策略。

全源码静态核查（235 Kotlin 文件、31 功能入口、36 子页面）及组件规则单测在本次改造通过。附加设备测试覆盖单项回复确认/取消、正常输入缺席、地址自动命名、原草稿保留及导航，CI 对最新提交执行编译/协议/Lint 和 Android 35 三档设备验收。真实服务端、实体设备与新画板视觉需按实际结果登记。
