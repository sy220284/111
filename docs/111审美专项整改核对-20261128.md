# 111 审美专项整改核对

依据《UI设计审美专项规范 V1.0》和 32 项登记功能的专项审计。本文件追踪实现及验收，不把提交、静态检查或示例数据等同于设计交付完成。保留 AGENTS.md、功能门禁、真实内核边界及现有动效预算。

| 编号 | 已落实的代码整改 | 最终验收 |
| --- | --- | --- |
| UI-01 | 稳定流式跟随、历史阅读锚点、按账号及会话保存位置与未读数；终端按实际输出跟随 | 四组设备及真实连续流式 |
| UI-02 | 汇总区分功能通过、设计受阻、待人工七维评审；读取原始动效采样与退出码 | 最新合并验收报告 |
| UI-03 | 导航截图核对实际页面或目标控件，前后验证窗口归属，拒绝错误主题及陈旧文件 | 实际图集逐张检查 |
| UI-04 | 目标与代码变更上下文、会话状态分组、过程轨迹和成果阅读区域 | 三秒扫描、任务场景一致性 |
| UI-05 | 开放内容、分组列表、状态、专业阅读及临时浮层分别组织 | 全页构图与留白 |
| UI-06 | 输入区压缩、任务控制和自适应动作布局，长内容目录在浮层内搜索 | 大字号、键盘、48dp |
| UI-07 | 目录恢复拥有连接提示，同页同原因去重，保留不同实际失败及动作回执 | 断连、重连及请求失败 |
| UI-08 | 终端、Diff、代码、全文、文件、队列、额度分别组织实际数据 | 真实业务填充态 |
| UI-09 | 锚定菜单、选择列表、短详情、危险确认和阅读面板按内容与风险布局 | 交互、退出、焦点 |
| UI-10 | 页面方向、菜单/面板、选中态、队列目标触感及执行过程反馈；减少动态效果偏好 | 连续操作和原始帧预算 |
| UI-11 | 两种设备规格的标准浅色、大字号深色；增加任务上下文、技能及应用详情必需截图 | 四组完整图集；真机独立验收 |
| UI-12 | 标题、正文、辅助文字及代码字体分工；语义状态色、图标、触控热区 | 实际对比度、灰度和可读性 |

验收分为功能、设计证据与人工审美三个层次。标准/自适应分别固定浅色/深色，截图时核对实际主题及目标；跨分片核对主题、运行标识、提交和 APK，旧主题图集不得冒充新主题证据。两种尺寸各执行同一功能测试集。独立的深色双倍字号测试保留。此矩阵不是所有主题与字号的笛卡尔积，真机交互、全部真实业务正常态以及七维审美仍须取得独立证据。审美结论只在证据齐全且实际画面评审通过后更新。
