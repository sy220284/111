## 代码级深挖：可执行子工程

### 1. Claude Test：浏览器+插件验证工具链

入口与依赖可以在 `resources/tools/claude-test/scripts/ct.mjs`、`playwright-mcp.mjs`、`ct-auth.mjs`、`lib/` 中找到：

- `ct.mjs`：项目识别、开发服务器探测、用例配置、安装检查、测试回合、结果与运行文件登记。
- `lib/allow-tool.mjs`：用户同意、网页启动、共享工具授权、运行会话归属检查。
- `lib/run-tools.mjs`：`claude_test_save/status/progress/write_log/finish/read/write` 工具、回合状态、任务目录和幂等记录。
- `playwright-mcp.mjs`：Playwright MCP服务器、browser action拦截、域名/输出审核、WebSocket与运行时证据。
- `lib/fence-proxy.mjs`：HTTP CONNECT代理、DNS解析、私网/本机地址拦截和上游代理条件处理。
- `lib/guard.mjs` / `lib/vet.mjs`：网页快照验证、域名和凭证输入限制、输出与文件路径审核、脱敏。
- `lib/signin.mjs`：浏览器授权存储、Skill认证脚本和项目隔离。

**发现的一项重要实际语义边界**：`ctbrowser.mjs` 在模块导入后有顶层 `process.exit(2)` 并明确提示浏览器规格必须通过受限Claude Test工具运行；下面的浏览器daemon代码因此不是正常可执行入口。这是显式的权限隔离约束，不能为了“功能恢复”擅自删除这个退出门禁。

本次可以用安全的纯函数实测网络围栏对 IPv4/IPv6私网、回环与IPv4映射地址的拒绝；验证 `NO_PROXY` 后缀不误命中相似域名、上游代理包含账号密码时拒绝使用、DNS pin规则错误输入被丢弃。尚不能据此证明真实DNS重绑定、代理链、动态MCP浏览器操作或密钥泄漏完全安全；需要实际隔离网络和完整宿主才能验收。

### 2. Design Sync：组件代码 → 构建 → 截图 → 差异 → 同步

`resources/tools/design-sync/` 包含 `resync.mjs`（总控）、`package-build.mjs`（构建和动态适配器）、`package-capture.mjs`（Playwright截图）、`package-validate.mjs`（检查构建完整性）、`storybook/compare.mjs`（对比）以及 `lib/sync-hashes.mjs`（共享内容哈希合同）。

已有验证确定12份原始资源恢复+6份嵌入辅助、14个 `loadLib` 动态适配器源文件及其声明导出均存在，入口的错误分支可启动。仍未验收真正的浏览器截图/视觉打分与真实的 `esbuild`、`ts-morph`、React组件构建，`.design-sync/overrides`动态覆盖路径也需要独立审计。因此“14个适配器能加载”不等于“整个Design Sync产品流程跑通”。

### 3. 模型协议、设计检查与SDK

- `resources/tools/evaluation/prefix_diff.py`：无外部依赖地对相邻Messages API请求的system/tools/messages/Thinking签名关联进行规范化和差异分类，不能把结构差异推断成模型行为100%一致。
- `resources/tools/evaluation/drop_block_probe.py`：读取捕获的真实请求并可经授权发起API重放；默认应只做 `--dry-run` 或静态审计，**不自动发送网络请求，也不读取用户私有令牌测试**。
- `resources/tools/design/scripts/validate_palette.js/.py`：设计色彩和样式约束校验，属工具而非主代理内核。
- `resources/tools/artifact/scripts/appifact_sdk.js`：通过宿主提供的文件描述符RPC处理文档、集合、文件和资产；源码已存在不代表宿主IPC已在111重现。

### 4. 预编译包与原生模块

- `src/mermaid.min.js` / `src/hljsBundle.generated.min.js` / `src/chart.umd.min.js`：3份独立预编译第三方前端包，需要与主业务函数数分开统计；字节一致性不等于浏览器渲染正确。

## 本轮验证手段与结论边界

- Git固定版本每份非主原始文件Blob核对；**工具、插件测试框架、嵌入源码、三个vendor产物应当与v37保持逐字节一致**，当前主分支中的额外研究脚本与CI修改另列。
- 47个工具JS/MJS解析函数、导出、静态依赖及动态导入；3个Python使用 `ast.parse`，绝不在验证中触发可能付费的模型API调用。
- 通过安全输入夹具直接执行真实网络围栏与凭据拒绝逻辑，并对类目录路径/权限边界做回归。
- v37已有17项非主源码定向行为证据只算局部覆盖；仍不能把全部代码标记为产品功能等价。
