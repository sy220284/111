# Android UI 设计系统 V2（四技能审计优化）

基于资料库 2026-11-20 上传的 UI 设计、工作台架构师、视频审美动效、术语四项技能，以原生 Android Compose 改进现有工作台。优先级是工作过程可信、操作路径清晰、风险确认明确，其次才是视觉层次和动效。具体问题、修改位置及验收路径见 [四技能交叉审计](UI_AUDIT_FOUR_SKILLS.md)。

## 设计方向

主题名：**石墨 · 暖铜（Graphite / Copper）**。
采用工作台和精密设备的视觉语言：深石墨主底，低光浮雕面板，细金属框，暖铜主动操作，雾玉绿作为执行成功状态，柔珊瑚红为审批风险与失败状态。减少高饱和装饰和大面积紫蓝渐变。

## 排版与布局

- 8dp 逻辑栅格，页面水平安全留白 18dp，卡片常规内边距 18dp，紧凑模式 12dp。
- 页面标题 26sp、副标题 14sp、主要内容 15sp；函数名、命令、JSON 和 Diff 使用等宽字体。
- 主交互高度 >= 44dp，紧凑列表行约 47dp，图标约 20–24dp。
- 竖屏小于 850dp 采用抽屉，宽屏 >= 850dp 使用常驻 288dp 左侧栏；面板独立滚动，代码展示占据主要空间。
- 导航原则：第一级为侧栏分组，第二级为功能页面，第三级为页面内详情、审核或弹窗。功能本身多，但用户路径不超过三级。

## 信息架构：28 个页面入口，四组折叠导航

| 入口组 | 页面 | 关键操作 |
|---|---|---|
| 工作台 | 总览、任务对话、会话历史、全文检索、任务目标、任务队列 | 创建、恢复、继续、查看 |
| 开发工具 | 工作区文件、代码差异、终端、代码审查 | 导入、编辑、查看、确认执行 |
| Codex 生态 | 模型目录、协作模式、技能、插件、连接应用、MCP 服务、触发钩子、执行环境 | 列表、详情、刷新、原生协议操作 |
| 设置 | 账号登录、模型服务商、引擎配置、权限与安全、待审批操作、使用量、使用限额、外观与交互、诊断与日志、关于项目 | 登录、配置、权限、状态 |

*以上共 28 个入口，侧栏按组展开并提供功能搜索、对话/文件/审批快捷入口。用户在页面内调用真实 RPC；对上游实验接口的错误使用原始服务端信息，不展示虚构数据。系统返回键按实际访问历史返回，关闭抽屉时先由原生组件处理。*

## 十二维落地审查

1. 结构层次：统一顶栏、侧栏、页面标题、主内容、二级卡片。
2. 比例留白：固定 18dp 页面边距与 12–16dp 面板间距，长输出独立滚动。
3. 字体系统：3 级信息权重、代码等宽、单行与多行职责区分。
4. 色彩秩序：暖铜强调操作位置，状态使用雾玉绿与风险红，不抢正文。
5. 材质表达：石墨雾面主材、0.7 倍细边框、轻浅顶部投影。
6. 形态一致性：按钮、卡片、菜单、标签统一曲率梯度 10/16/24dp。
7. 内容真实度：模块从运行核心读取，空白态和错误态明确。
8. 触控人因：任务发送底部固定输入区，审批按钮与拒绝按钮区分。
9. 反馈状态：连接、加载、审批、运行和失败均有显式指示。
10. 动效节制：按压反馈约 110ms、详情展开约 210ms、页面导航约 240ms；减弱动效设置使自定义动画即时完成。
11. 跨屏适配：手机抽屉、平板常驻栏；输入区跟随 IME 安全区。
12. 系统一致性：依托 Material 3、窗口安全区与 Android 系统返回/权限入口。

## 页面动效与交互约定

- 导航：移动端使用 Material 3 `ModalNavigationDrawer`，宽屏为常驻侧栏；侧栏按组展开/折叠，支持功能搜索和直达高频页面。换页收起键盘、清理输入焦点；Android 系统返回键根据历史返回上一页。
- 动画分级：按压反馈 110ms、内容展开 210ms、页面转场 240ms。由 `CodexMotion` 统一管理，减弱动效设置可即时关闭自定义动画。
- 底部选择弹层：`CodexChoiceSheet` 用于模型和协作方式；选项保持清晰的选中状态、滚动容器与手指操作空间，背景交互由 Material 3 管理。
- 安全确认：`CodexConfirmDialog` 用于命令、权限、本会话持续授权、配置写入、删除、退出、插件操作及 MCP 授权，展示操作对象与影响，取消不改变服务状态。
- 任务流：`TimelineStepCard` 显示工具类型、真实执行信息、状态与来源记录；点击打开 `CodexEvidenceSheet` 底部弹层，支持复制原始记录。用户阅读旧步骤时保留滚动位置并出现新步骤计数；只有已处于底部才跟随新步骤。
- 执行状态：运行中提醒和固定在底部输入区旁的“停止”按钮保持可见，闲置时停止按钮禁用；审批状态在首页和会话均可直达；正在执行时新建会话入口禁用，状态管理也防止清空当前运行任务。
- 密度与材质：紧凑布局和柔雾面板可独立保存并实际改变全局 UI；颜色只承载文本层级、操作优先级、成功与风险。
- 适配：输入区避让 IME，长代码/JSON 可以逐段滚动，系统弹层与对话框遵循安全区及系统返回键。

## 组件职责

`CodexTheme`：颜色、字阶、圆角。 `MaterialPanel`：全局材质。 `SectionIntro`：页面信息层级。 `StatusPill`：状态标签。 `Sidebar`：四组折叠、搜索与直达入口。 `CodexNotice`：带操作按钮的真实事件提示。 `CodexEmptyState`：首日无数据引导。 `CodexChoiceSheet`：手机端底部选择。 `CodexEvidenceSheet`：可复制原始步骤依据的详情弹层。 `CodexConfirmDialog`：统一风险确认。 `CodexReveal`：可减弱的内容展开。 `CodexActionTile`：带触摸状态的任务入口。 `TimelineStepCard`：可展开依据的步骤流。 `ConversationPage`：运行与历史上下文、模型选择、任务执行。 `ApprovalsPage`：服务端实际人工审批入口。

## 完成标准

大多数操作 1–3 步内可到达；每个需要服务端数据的页面具有加载、错误、空数据与成功的展示路径。安卓 CI 需要编译、Lint、协议契约检查、单元测试与模拟器交互测试。需真实测试：首页及侧栏截图、模式选择弹层、执行依据详情弹层、外观页面、搜索跳转、终端确认与取消、系统返回键。发布前补充多尺寸、系统字体放大、TalkBack、键盘避让和真实 Codex 核心的端到端测试；具体结果以 CI 和验收记录为准。
