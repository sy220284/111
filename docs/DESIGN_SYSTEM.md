# Android UI 设计系统 V3 · 典雅白

版本：2026-11-21。四技能审计后的实现规范，适用 111 Android 28 个 Compose 页面。

## 统一视觉
**页面、面板、卡片、底部导航、弹层、按钮和强调状态背景全部为纯白 #FFFFFF。**
使用字色 #263139，说明文字 #56646D，细描边 #D8DEE1，暖铜 #805A3F（主要操作），青绿 #246F54（正常成功），朱红 #AC363A（危险错误）。
暖铜、青绿和朱红只用于文字、图标、描边与进度；主要按钮为白底铜色描边。
Material 3 的 `surfaceContainer*`、`primaryContainer`、`secondaryContainer` 与 `errorContainer` 保持白色，所有默认卡片与弹层采用浅色主题。
`softMaterial` 仅控制轻阴影，不再绘制渐层或更改底色。

## 四技能落地
- finesse-ui：白底统一、精确对比、细边框层级、视觉比例、留白和 48dp 触控目标。
- finesse-brief：28 页按工作任务组织、底部常用入口、主任务优先、专业功能搜索可达。
- frame-smith：反馈 110ms、展开 210ms、转场 240ms；减弱动画时仍有静态边框按压反馈。
- finesse-term：操作与状态优先中文、减少重复英文眉题；协议原文仅放专业详情。

## 布局与任务
对话控制条在 360/393/411dp 单行呈现模型、模式、诊断、添加图片，后两个按钮各 48dp；输入区默认 1 行最多 5 行；独立停止和发送。工作任务运行时显示真实步骤数量与最近执行内容。
首页主入口及发送等高优先级动作有独立强调描边；审批、错误、实验状态分别按危险/中性等语义表达。
正文只显示一次解释性标题，顶栏提供页面位置，原始 JSON 和运行依据按需展开。

## 验收
执行 Kotlin 编译、单元测试、Android Lint、协议测试和 360/393/411dp 模拟器 UI 测试，保存截图逐项检查纯白背景、色彩对比、页面滚动和输入区高度。
