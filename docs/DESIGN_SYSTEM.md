# Android UI 设计系统 V4 · 典雅白工作台

版本：2026-11-21。按照界面审美、工作台架构、动效与术语四项技能整体验证的新版原生 Compose 规范。

## 视觉风格
参考提供的 DSH 对话与设置截图：大圆角、浮动圆形控件、中央欢迎区、两列任务卡片、设置页分组白色容器、底部工具抽屉。保留前一版明确的视觉约束：页面、面板、强调状态、卡片与弹层均为纯白 `#FFFFFF`；标题深灰 `#263139`、辅助字 `#56646D`、细边线 `#D8DEE1`；暖铜 `#805A3F`、青绿 `#246F54` 与危险红 `#AC363A` 用于字、图标和描边。图标圆形容器为白底，使用轻量描边营造彩色层次；无彩色实底卡片。

## 整体导航
- 左侧抽屉固定六个常用入口：首页、任务对话、会话历史、工作区文件、待审批操作、设置。所有其他专业入口从侧栏移出，不再出现冗长的菜单列表。
- 手机底栏仅首页/对话/文件/会话/设置五项；对话页面隐藏底栏，把空间留给任务消息和输入框。顶部圆形按钮可展开侧栏；从设置内的二级页面使用返回箭头。
- 新增“设置”聚合页，按五组呈现原有 23 个较低频功能：账户与模型、扩展能力、任务与开发、主机与安全、通用与外观。设置页支持按中文标题、用途说明和协议路由检索。
- 用户在聊天界面点击输入区“+”展开底部工具抽屉，可以选择本地图片，或访问工作区、Diff、终端、审查、目标与队列。首页和工作区顶部也提供同一个快捷工具入口。菜单项目均有真实功能路由。
- 保留原有 28 个页面与原始 RPC，聚合页为第 29 个页面。所有页面拥有唯一入口，一级导航和二级功能选择构成最长三级用户路径。

## 组件与交互
- 首页和空对话界面提供中央问候、操作说明与双列快捷卡片；卡片点击后调用现有功能或填入可编辑草稿。
- 设置页使用带描边与轻阴影的圆角分组卡片，组标题位于外部；每个功能行包含圆形图标、中文名称、简短说明及箭头，行高不低于 70dp。
- 状态信息来自实际运行内核，审批数量从服务端事件流读取，详情页保留真实数据、确认、加载和错误处理。
- 输入框左侧加号唤起底部工具抽屉，模型与执行模式保留紧凑的一行控制；发送和停止仍为明确分开的操作。
- 保持减弱动效、可读对比和原生 TalkBack 标签；按压时使用边框反馈，转场与弹层采用 Material 3。

## 验收标准
- 28 个旧页面路由全部可达且不能重复；抽屉恰好六个入口，分组设置恰好 23 个原有入口，快捷菜单引用现存功能。
- Kotlin 编译、单元测试、协议检查、Lint、原生 APK 构建和 360/393/411dp Android 35 实机模拟交互均通过。
- 在三档屏宽检查首页、侧栏、对话、设置中心、附件抽屉、审批、登录、Diff、终端确认、插件和其他原有截图，确认无溢出、文字遮挡或背景色残留。
