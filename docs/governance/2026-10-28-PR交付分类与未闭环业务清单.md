# 111 全部 PR 交付分类与未闭环业务清单（2026-10-28）

## 分类与验收标准

五类唯一主标签：**真实业务源码恢复、缺陷修复、工具维护、独立测试、文档维护**。旧“治理配置”“目录整理”按变更内容归入工具或文档维护。以下已为本次审计覆盖的 #1–#46 添加对应 GitHub 标签（新增 #44/#45 单独复核）。

- “真实业务源码恢复”要求确实修改业务 `src/` 中的实现，但仍须另行确认合并状态与业务消费者链的证据；具名/局部函数测试不等于功能完成。
- “缺陷修复”是具体问题源码修复。其真实调用链只能覆盖 PR 测试实际达到的边界。
- “工具维护”包括 CI、源码分析、反编译包、目录门禁和开发工具；不抵扣业务缺口。
- “独立测试”包括真 CLI/工具/本地宿主的运行验证；PR 自身未改业务源码，不可计入新增恢复。
- “文档维护”包括状态矩阵及治理规范。
- 仅 `main` 已合并且有最终提交真实业务调用测试成功记录的范围，才能登记为主线业务已交付。
