# 真实运行验收执行手册

每次验收以候选 Git SHA 为唯一标识。通过 `.github/workflows/ci.yml` 的「111 统一质量验收」入口执行，使用当前提交的变更分类及设备矩阵；`build-native-codex.yml` 仅为原生构建可复用入口。main 基线仍为 Android 35 的 360/393/411dp，关键核心/权限/远端输入变化自动启用 x86_64 真实核心；#116 候选改为 Android 17 API 37、37.2 16KiB、八个 UI 分片与真实 x86_64 核心全量联合验收，完整检查不能改成仅手动 x86。不存在旧独立 build-android.yml 生产入口。真实运行作业保存 ABI、API、APK SHA-256、逐项 instrumentation 原始日志及结果。设备及真实服务缺席按待验记录，不以旧结果替代。参见 [CI 统一交付流程](CI统一交付流程.md) 与 [现行实现索引](现行实现与文档维护索引.md)。

## 实体 ARM64 手机（专用测试设备）
从同一候选的「安卓版本构建与验证」下载并解压 codex-android-arm64-apk 与 codex-android-instrumentation-apk；确认设备已开启 USB 调试、可执行 adb，且未安装日常 111。不要用日常项目、账号或签名覆盖测试设备。选中唯一设备（多台时设 ANDROID_SERIAL）。在仓库根执行：

```sh
bash .github/scripts/run-android-runtime-tests.sh \
  app-arm64-v8a-debug.apk app-debug-androidTest.apk arm64-v8a evidence-arm64
```

保存 evidence-arm64、候选 SHA、测试手机型号/Android 版本，以及真实后台保活、锁屏、切换网络、系统回收、权限撤销和恢复的人工结果。脚本遇已有 111 会停止，不会覆盖。运行后保留测试安装供登录和服务测试，不清除或上传个人数据。模拟器回执独立于实体设备回执。

## 真实账号与第三方服务（操作者明确启用）
在同一专用设备打开 111、完成真实账号或自定义模型配置，使用一个明确授权的测试模型与隔离测试账号；如需 MCP，配置已获授权的测试服务。确认当前无运行任务，再关闭应用（adb shell am force-stop io.github.sy220284.codexandroid）。使用同候选测试 APK：

```sh
adb shell am instrument -w -r \
  -e class io.github.sy220284.codexandroid.LiveServiceInstrumentedTest \
  -e liveService true -e liveModel '<已授权模型 ID>' \
  io.github.sy220284.codexandroid.test/androidx.test.runner.AndroidJUnitRunner
```

可附加 `-e liveMcp '<测试服务器名称>'` 验证该服务器的真实连接状态。此用例创建独立空目录、临时只读会话，发送随机测试标记，核对真实 turn/start 回执、turn/completed 状态和模型正文；未授权时直接失败，不自动登录，不读取私人项目，不在证据中记录凭据或正文。可能消耗测试账号额度。MCP 的状态检查仅证明连接；具体工具调用须选择无副作用的测试工具并核对真实回执。

语音、远程配对、OAuth 和真实 MCP 工具调用仍需有对应账号、权限、麦克风或第二台设备。人工记录：语音实际采集/静音/关闭及断线恢复；远程设备配对、真实列表、撤销后失效；OAuth 同意、取消、令牌过期及恢复；MCP 连接、只读工具调用与失败恢复。每项保存候选 SHA、设备型号、真实结果与脱敏时间戳。不以连接状态代替功能回执，也不将未执行项目登记为通过。

## 合并与发布
通过 `ci.yml` 的固定「111 合并验收」及目标提交适用的全部作业；`release.yml` 再校验同 SHA 的统一验收、真实签名 APK 和专用 ARM64 实机回执。ARM64 二次核验、x86 真实运行、所有设备分片分别保存证据；真实服务、外部工作站及发布回执独立登记。主分支保护以实际 GitHub 规则回读为准。

## 发布后整机压力观察（#116 候选）

[独立专项执行手册](https://github.com/sy220284/111/blob/6601a28c37b8e80a0f2123305c51971d03b6785d/docs/发布后整机压力测试.md) 使用正式发布 APK 摘要确认已安装应用，并仅安装同源同签名测试 APK。5000历史、50万 UTF-16 单元/轮、默认30分钟100次/秒，帧/CPU/PSS/整机能耗及不可用原因据实记录；此专项不进入发布前门禁，也不替代常规交互、功能、安全及真机验收。
