# 111 安卓端全层级页面、按钮、组件及弹窗审计（2026-11-23）

> 历史层级核对，当前入口、容器及设备配置以 UiFeatureCatalog、AppNavigation、三份权威规范和 [现行实现索引](现行实现与文档维护索引.md) 为准。保留原 29 个入口及 28 个元数据项的审计口径。

## 目标与统一规则

基于已合并的 PR #55 和 #61，在 `main` 最新工作流上复查完整 Android 界面。以“用户正在做什么”为页面设计起点。长时间连续阅读或编辑的对象可进入全屏工作区；选择、确认和短时间操作在当前上下文打开弹层；设置仅保留持续性的偏好与授权。会话入口固定在侧栏，审批与执行反馈靠近当前任务。各级导航需保留来路与关闭路径。

本审计核对 **29 个注册功能入口、28 个页面元数据项**，以及 Compose 源码中的各级操作控件和弹层；所有注册入口均纳入 CI 自动校验。接口声明与按钮点击的源码关联由既有 `audit_ui_feature_coverage.py` 和 `ui_surface_policy.json` 负责；本次扩展页面归属与空处理器检查。实际运行仍通过 Android 35 的 360/393/411dp 仪器测试验证。

## 三级详情、编辑器和弹窗检查

| 所属对象 | 详情/弹窗 | 实际核查重点 |
|---|---|---|
| 会话侧栏 | 会话切换与会话搜索 | 当前选中态、跨项目归属、搜索返回原任务 |
| 会话管理 | 全文搜索、归档、批量操作、分组/重命名/删除确认 | 结果属于当前会话或全局；取消后返回列表；保留数据安全确认 |
| 当前对话 | Queue/Steer、附件图片菜单、停止执行、审批 | 任务中输入和反馈就地可见；执行中禁用原因清晰 |
| 会话操作 | `ThreadContextTools`、`ThreadGoalSheet`、`ThreadQueueQuickSheet` | 关联活动会话、读取真实目标/队列、编辑与删除前确认 |
| 会话历史 | `ThreadHistorySheet`、`AdvancedThreadTimelineDialog`、`FullTextReaderDialog` | 回退前告知文件不会自动恢复；详细阅读和原路返回 |
| 附件 | `ThreadAttachmentsSheet` | 添加、移除、确认、错误与关闭 |
| 终端 | 命令执行确认、PTY/尺寸、输入、停止、历史 | 输出优先；输入与停止始终可见；危险操作先确认 |
| 文件 | 目录选择、导入、新建、重命名、复制、删除确认 | 新建按需展开，完成后关闭；列表继续可见 |
| 项目 | `ProjectRegistryPanel` | 项目登记、切换、重命名、顺序调整与删除独立确认 |
| 插件 | `PluginDetailSheet`、技能正文阅读、安装/卸载确认 | 在插件详情先理解能力，再决定安装；对话内调用工具 |
| 扩展 | `McpElicitationRequestCard`、MCP OAuth 确认 | 必填及格式有效后才启用确认；取消和拒绝分离 |
| 账号 | 设备码登录、浏览器授权、`AccountSessionsSheet`、退出确认 | 切换/退出可确认；用量与额度使用统一入口 |
| 服务商 | 自定义服务商编辑、默认项确认 | 内核字段转为用户可理解的名称，保留必要的服务地址 |
| 安全 | 权限方案查看、策略变更确认 | 权限清单按需展开；实际影响在确认窗写清楚 |
| 执行环境 | 本机/远程选择、连接表单、状态详情 | 选择位置后才显示连接参数，连接状态与提交结果区分 |
| 设置/诊断 | 外观内嵌控件、更新/备份、连接重试与日志详情 | 一处配置一处入口；排查技术细节按需展开 |

## 点击与组件的统一验收规则

每个可操作控件至少覆盖 **可见/可点击条件、点击后的实际动作、处理中状态、成功或错误反馈、取消和返回** 六个要点。确认窗需要区分浏览操作与变更操作；保存、移除、恢复、授权、执行命令须有用户可见的影响说明。按钮因运行中、断连、缺少会话而禁用时，应提供明确原因；空数据时给出下一步操作。一级、二级和三级组件都使用同一套交互反馈、主题、间距和辅助功能语义。

### 本次实际落实的更改

1. 将独立“用量”和“限额”设置合并成“用量与额度”，保留独立标签及历史路由；页面与测试同步。
2. 工作区文件新建表单改为点击“新建”后出现，创建完成后恢复目录浏览。
3. 技能页合并重复章节标题和错误提示，保持每个技能独立启停确认。
4. 引擎配置页移除重复功能导航，保留专业配置的校验和保存确认。
5. 诊断页默认使用用户操作语言，技术排查内容按需展开。
6. 安全设置移除重复审批跳转，权限方案改为按需展开，保留策略更改确认。
7. MCP 表单的提交按钮直接复用真实协议校验，在必填项未完成时提示并禁用。
8. 扩展既有 `audit_ui_feature_coverage.py`：检查目录入口唯一、Sheet/Inline 实际组件、设置与任务边界、空点击处理器，并由 CI 运行。
