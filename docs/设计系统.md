# Codex Android · 桌面式移动工作台设计系统 V6

## 设计目标

以 Codex 桌面版的「项目 / 会话 / 执行 / 审批」工作流为统一模型，在 Android 手机竖屏上统一导航归属和真实业务能力。所有手机屏宽都通过顶栏与抽屉侧栏访问工作区。用户在任务上下文中完成主要操作，后台协议与内部存储字段只参与程序判断和诊断。

主界面遵循「任务优先、内容优先、真实状态、明确后果」。全部原有 28 个业务路由继续保留；不以技术接口数量决定导航数量。

## 唯一导航结构

- **手机**：顶栏左侧打开单一侧栏；正在设置子页时显示返回上一页；不渲染底部导航条。
- **侧栏顶端**：Codex 标识、当前工作区、全局新建任务。
- **工作台**：首页、任务对话、会话历史。
- **工作区**：工作区文件、待审批操作（有待处理项时出现数量）。
- **侧栏底端**：设置与真实内核连接状态。
- **专业工具**：文件、Diff、终端、代码审查、目标、队列进入任务或工作区的工具面板；技能、插件、连接应用、MCP、模型、账号、安全、更新属于设置中的长期能力配置。
- **层级**：一级为当前任务和导航入口，二级为功能列表，三级为设置或操作详情。返回沿用户实际访问路径回退。

重复入口处理：移除原手机底栏五槽目录及相关路由依赖；统一抽屉与顶栏调用同一 navigation policy，手机不同屏宽保持一致的任务入口与返回路径。

## 任务主流程与能力融合

| 用户目标 | 首选操作 | 真实业务执行 | 用户可见的结果 |
| --- | --- | --- | --- |
| 开始工作 | 侧栏或首页「新建任务」 | `newThread()` → `thread/start` / `turn/start` | 新任务草稿与正在执行的状态 |
| 继续任务 | 会话历史搜索、选择会话 | `thread/list`、`thread/resume`、`thread/read` | 会话标题、更新时间、可继续的内容 |
| 编写要求 | 对话输入与发送 | `turn/start`；运行中 `turn/steer` | 用户消息、回复、运行进展 |
| 添加文件上下文 | 对话输入区「+」 | 本地图片导入；`thread/attachment/*` 相关上下文操作 | 已选择附件和本次发送状态 |
| 使用项目工具 | 同一个「任务工具与附件」面板 | 工作区文件、本地终端、Diff、审查、目标、队列 | 对应真实页面或面板 |
| 检查变更 | 任务工具 → 代码差异 | 已有 Diff 数据、审查 `review/start` | 按文件查看改动与审查 |
| 执行命令 | 任务工具 → 终端 | 现有 `command/exec` 等终端能力 | 命令确认、输出、停止 |
| 决定审批 | 待审批操作、顶栏状态或任务提醒 | 运行时 `item/*/requestApproval` 回调 | 操作内容、风险范围、拒绝/允许 |
| 使用扩展 | 设置 → 技能、插件、连接应用、MCP | `skills/list`、`plugin/*`、`app/*`、`mcpServer*` | 可用状态、可执行管理操作 |
| 修改安全设置 | 设置 → 权限与安全 | `config/read`、`config/batchWrite` | 中文权限级别、确认内容、实际保存结果 |

关键交互：对话区模型和协作方式紧邻输入框；状态图标查看引擎状态；输入区附件按钮添加图片；模型、模式和诊断位于输入区任务选项；工作区文件、终端及会话操作从任务顶栏进入，Diff/审查、目标和队列从相关任务上下文进入；全局设置只管理长期偏好。执行中允许通过原有 `turn/steer` 增加指令；停止操作继续保留。

## 业务数据与界面的展示边界

统一使用 `PresentationPolicy` 作为用户文字转换层，后台数据结构和请求参数保持原样。

| 后台值 / 原始字段 | 普通界面使用 |
| --- | --- |
| 线程 ID、回合 ID、UUID、文件内部绝对路径 | 以会话标题、工作区名称、文件显示名替代 |
| `null`、`undefined`、空名称 | 「未命名会话」「本机工作区」等语义空状态 |
| `userMessage`、`agentMessage`、`mcpToolCall` | 「你的指令」「Codex 回复」「工具调用」 |
| `read-only`、`workspace-write`、`danger-full-access` | 「只读」「可编辑工作区」「完全访问（高风险）」 |
| 技能缓存路径与根目录 | 技能名称、启用状态、可展开说明 |
| 连接应用原始 JSON | 已授权 / 可调用状态与工具名称 |
| 错误与运行细节 | 先展示可理解的原因和操作；详细诊断在专业界面查看 |

判定原则：只展示有实际意义的状态值。不使用后端字段名称或文件路径兜底当作普通业务标题。原始数据只保留在业务层和明确的诊断/执行依据入口中，供用户主动检查。不得在首页、导航、历史列表、技能列表和权限总览中直接展示 JSON、RPC 标识、UUID 或私有存储路径。

同一用户输入仅在对话时间线显示一次：本地乐观消息和后续服务端 `userMessage` 事件合并，保持真实文本和官方执行事件。

## 视觉与尺寸

保留「典雅白」：页面与面板纯白 `#FFFFFF`、主要文本 `#263139`、说明文字 `#56646D`、细线 `#D8DEE1`，**珊瑚 `#C8483E` 为主操作强调色**，暖铜 `#805A3F` 仅用于次要强调，青绿 `#246F54` 为已连接/已完成状态，危险红 `#AC363A` 用于异常和危险操作。避免整块彩色背景、深色大卡片及过度阴影。

圆角用于大面板、细分列表和输入框，层级依靠留白、标题和轻描边区分。常用控件点击区域至少 48dp，特别关注手机宽度 360 / 393 / 411dp。对话消息与工作区文件占据主体面积；状态和诊断只在需要时出现。支持系统字体缩放、TalkBack、减弱动效和键盘遮挡适配。

## 验收标准

1. 旧业务路由保留，侧栏六个常用入口可达；所有屏宽均没有 `main-bottom-navigation` 组件。
2. 对话附件按钮打开真实图片选择器；任务选项和任务顶栏访问真实工具；仍能发送、停止、补充指令、查看模型与执行模式。
3. 首页、会话列表、对话记录、技能列表、权限及连接应用显示真实的用户可理解文字，不直接露出 `null`、路径和原始类型值。
4. 代码变更应通过 Kotlin 编译、协议覆盖、单元测试、Lint、Debug APK 构建以及 Android 35 的 360 / 393 / 411dp 真机模拟交互截图。
5. UI 和 Figma 使用一致的信息架构与交互词汇；Figma 页面必须保留可编辑文字、矢量图标和组件层。

技术功能范围按 `UiProtocolMatrix.kt` 及 `ui_surface_policy.json` 源码审计；交付验证以同一提交的实际 CI 和设备截图结果为准。

### 手机竖屏键盘布局原则

主页面使用系统 `adjustResize` 确定输入法展开后的可用窗口，页面主容器随窗口缩放。输入法状态只控制次要工具是否折叠，发送、附件和任务入口应一直显示；同一高度不在父子两层重复计算。


### 权限与安全页：操作优先的卡片布局（2026-11-23）

- 页面依次显示「当前默认权限」摘要、「调整范围」双选卡片、「选择权限档位」列表和保存入口。进入页面默认展开档位选择，允许用户直接理解、点击和完成操作。
- 沿用 `Ink` 语义颜色：纯白面板 + 轻描边，选中状态使用珊瑚细描边和低透明度底色；已读取使用青绿状态；高风险使用危险红文字。避免两层重复标题、连续大面积警告色及无意义的“可用”状态标签。
- 同一档位兼顾说明、选中、受限与危险状态：可操作整行触控目标至少 48dp，受限项保留可读原因并呈现禁用语义。完全访问保存前二次确认。
- 新任务默认与当前会话权限分别选择、分别保存；页面随选中的范围更新操作按钮与生效说明。状态来自真实 RPC，保存失败与覆盖时展示具体错误。
- 360/393/411dp、浅色/深色、字体放大、滚动、长说明文本及 TalkBack 交互均采用同一组件布局；截图验收必须包含真实权限档位和选择状态。
- Figma 目标文件仍为既有 `K4FEMoNdmQbcnJZCHWr8c7`；Figma MCP Starter 配额暂不可调用，实际画板尚未写入，本次 Android 页面与测试先以代码实测为准。

## 2026-11-23 决策优先视觉精修（PR #74）

### 操作层级

- 第一层：`CodexPrimaryButton` 是深墨实心，暗色主题用亮色实心反转；用于当前页面最重要的保存、允许、连接、审查与确认。主按钮在同一区域一般只出现一个。
- 第二层：`CodexSecondaryButton` 是中性描边；用于拒绝、返回、取消、相邻辅助操作。
- 第三层：`TextButton` 或功能行；导航用行尾箭头，展开用向上/向下箭头，会话持续授权放“更多”菜单并二次确认。危险动作以红色标记，永久删除与完全访问的确认框最后一步才展示实心红色。
- 审批中的命令、路径与权限范围以可读形式默认显示，长命令可展开；按钮顺序让拒绝与仅本次允许清楚区分。任何实际授权仍由原来的 `ServerPrompt` 和 `ApprovalAction` 执行。

### 页面与状态

- 会话资料库和全文搜索作为全屏 Page，顶栏有返回和新建，搜索第一、分段单选筛选第二、结果列表第三、批量管理贴底。任务必须选择会话时保留带关闭键的轻量 Sheet。
- 模型、模式选择 Sheet 仅列真实可选项；连接/刷新走独立恢复条，不占用 radio。所有长内容 Sheet 应有清楚的关闭操作。
- 未连接、加载、无数据、失败分别展示实际状态；`CodexRecoveryState` 统一重连、重试与前往诊断的交互。禁止在已经失败时继续显示加载文案。
- 在技能、插件、应用和 MCP 列表中保留现有本地数据与协议来源，MCP 仍为智能体管理的只读“可用服务”目录。
- 200% 字号优先保持自然高度、横向可滚动单选项和 48dp 触控；使用既有 `CodexMotion` 尊重减少动效，避免与状态无关的装饰转场。

### 四项技能的落地边界

1. `finesse-ui`：决策主次、空态有下一步、窄屏阅读优先。
2. `finesse-brief`：工作台仅展示用户任务对象与真实能力状态。
3. `frame-smith`：沿用克制的状态反馈、触控响应和减少动画。
4. `finesse-term`：统一“仅本次允许 / 本会话持续允许 / 拒绝请求 / 稍后处理 / 未读取”等操作词。

原生 Android 保留 Compose 与现有界面状态令牌，不引用技能包网页实现文件作为运行依赖。视觉验收以同一 PR SHA 的 CI 设备截图为准；Figma 画板必须独立确认写入、截图回读。

## 次级内容的呈现规则（2026-11-23）

- 默认页面只保留可执行主动作、必要状态和可理解的摘要。“查看更多、查看说明、启动日志、额外配置、文件管理”等次级内容打开独立底部面板，使用 `CodexDetailTrigger` + `CodexDetailSheet`，避免在点击行下方插入整块内容造成列表移动。
- 文件与会话的“更多”调用 `CodexActionSheet`，显示完整中文操作语义，危险动作仍走业务层二次确认。底部面板支持拖动半屏/全屏、内部滚动、48dp 关闭按钮和 IME 避让。
- 已处于底部面板时，简短详情使用 `CodexInfoDialog`。运行进度、选中状态、核心权限列表、Diff 文件展开与当前表单的必要字段保留在原位，可立即观察或编辑。
- 共享组件实现位于 `CodexDetailSheet.kt`，组件与十张参考图的映射、可导入 Figma 的 SVG 素材见 `docs/交互组件图谱与替换规则-20261123.md`。保持 Ink 原有令牌和 360/393/411dp / 200% / 深色 / 语音辅助验收。

## 详情面板与表单确认的自适应规范（2026-11-24）

详情与信息对话框的滚动区以当前窗口高度为边界，保留标题、关闭与主要操作，适配 360/393/411dp、小高度窗口、系统大字体和软键盘。目标额度等可选编辑使用 `CodexEditDialog`，确认修改后进入会话草稿，真正保存由所在任务页面发起；关闭/返回与取消不得触发业务写入。执行状态以单选控件表达，保留“进行中/已暂停/遇到阻碍/已完成”的唯一选中语义。适用组件和验收见 `docs/交互组件图谱与替换规则-20261123.md`。

## 2026-11-24 全局视觉素材与容器统一

86 个 24dp 矢量图标采用 1.8 线宽、圆角线端及转角，所有应用调用通过 `CodexIcon`；系统通知保留原生单色资源。SVG 源与 Android VectorDrawable 路径一一对应，语义颜色随 Ink 双主题和真实业务状态变化。

七类插画（新会话、无内容、无搜索结果、请求失败、无差异、无审批、断连）提供亮暗独立矢量；插画不包含文本、不替代原因与恢复动作。新会话的装饰只在剩余高度足够且键盘隐藏时展示。

统一底层 `CodexSheetFrame` / `CodexDialogFrame`，保持复杂任务的业务布局和返回路径；搜索、状态进度、空态、反馈及上下文操作复用共享组件。新增组件设计源见 `ui-assets/状态与交互组件.svg`；全路由和素材接入证据见 `ui-assets/素材接入清单.json`，由 CI 输出逐项报告，设备结果以当前实际 CI 为准。


## 全页面交互推广（2026-11-24）

统一搜索、排他选择、列表数量、操作反馈与自适应详情；使用 `AtlasChoiceRow` 表达可访问的单选，`AtlasCompactChoice` 表达短选项。业务未返回的数据明确标为未读取。长正文沿用独立阅读器，短详情置于对话框，不推动原列表。以 `android-app/tools/ui_interaction_coverage.json` 逐入口核验源码，设备截图及 Figma 回读另行验收。


### V6 全场景补核（2026-11-24）

- 消息标题及更多按钮打开相同菜单；长按标题提供系统触觉反馈，正文保留系统文本选择。全文命中通过实际文本布局定位到对应行。
- 资料库整行点击进入活跃会话，归档行打开管理菜单；长按只选中可管理会话。队列编号长按拖动到可见目标；完整队列读回后才允许真实排序，更多菜单保留上下移无障碍路径。
- 文件编辑器独立全屏，异步严格读取文本；未保存确认、外部变化检查、草稿复制及原子保存；更新和备份复用状态反馈。断连目录保留旧数据并明确标记。
- 29 项功能入口及 25 个子页面登记于交互覆盖清单；新增文件编辑、全文定位、消息菜单、附件预览和更新进度设备截图。静态证据、设备结果、实际内核和 Figma 原画板分别验收。
