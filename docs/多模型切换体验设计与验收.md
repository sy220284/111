# 多模型切换体验

> 设计与场景保持；设备配置按目标提交的 [CI 流程](CI统一交付流程.md)。模型目录、强度和服务商切换只能按真实回执判定，Figma 或旧截图不作为最新能力证明。

设计采用现有 Ink 主题、48dp 触控和共享选择组件，模型选择与强度同面板，当前运行时保留下一轮入口。跨厂商通过原生分叉继续，历史交接须确认，原会话未发送草稿保留。详见 [原型](ui-assets/model-switch-experience.svg)。Figma 文件 https://www.figma.com/design/s0dPypbc9bhwddiIcgTTU8 已创建，Starter 调用额度阻断画板写入，SVG 是仓库内可编辑替代源，未完成在线画板核验。

验收：1. 同服务商连续选择 A/B/A，恢复支持的显式思考强度；2. 目录加载、刷新失败、断连和重连；3. 运行中选择下一次普通发送，当前任务和已排队任务不受影响；4. 跨服务商先确认，取消不创建；成功校验新 ID、目标服务商、模型并打开历史；5. 失败原会话草稿不丢失；6. 深浅色、目标提交设备矩阵、键盘、200% 字号与减少动效；7. 各真实服务商的工具和历史协议兼容性单独验收。当前未执行真机或真实账号验证。

模型目录根据官方 Model.inputModalities、isDefault、supportedReasoningEfforts 生成真实能力提示；当前草稿含图片而目标声明仅文本时在选择列表提示。按服务商隔离最近选择排序，每个会话最多保留24条，切回历史会话时恢复偏好；新增最近使用与能力数据解析单测。ultra 继续遵守现有客户端过滤策略，未变更多智能体/派生执行能力。
