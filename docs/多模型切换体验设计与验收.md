# 多模型切换体验

设计采用现有 Ink 主题、48dp 触控和共享选择组件，模型选择与强度同面板，当前运行时保留下一轮入口。跨厂商通过原生分叉继续，历史交接须确认，原会话未发送草稿保留。详见 [原型](ui-assets/model-switch-experience.svg)。Figma 文件 https://www.figma.com/design/s0dPypbc9bhwddiIcgTTU8 已创建，Starter 调用额度阻断画板写入，SVG 是仓库内可编辑替代源，未完成在线画板核验。

验收：1. 同服务商连续选择 A/B/A，恢复支持的显式思考强度；2. 目录加载、刷新失败、断连和重连；3. 运行中选择下一次普通发送，当前任务和已排队任务不受影响；4. 跨服务商先确认，取消不创建；成功校验新 ID、目标服务商、模型并打开历史；5. 失败原会话草稿不丢失；6. 深浅色、360/393/411dp、键盘、200% 字号与减少动效；7. 各真实服务商的工具和历史协议兼容性单独验收。当前未执行真机或真实账号验证。
