## 运行时保护与证书边界

- 签名 APK 数据逐项验证内容、目录、额外文件及链接；通过后统一移除运行时数据的写权限。私有用户依赖安装目录保持独立可写，受损版本按签名来源重建；删除受保护目录时不得追随链接或更改外部文件权限。
- Android 内核与应用仍共享 UID；同 UID 可改回文件权限，启动校验和只读模式只负责防误写与跨启动完整性，不能证明运行期间的系统级隔离。实际权限边界仍须专用设备验证。
- 默认只采用 Android 系统信任根；仅在证书集合内容确实变化时原子重建 CA 文件。用户安装的企业证书当前不自动纳入开发工具信任范围；不以关闭 HTTPS 证书校验替代企业 CA 支持。
