# 安卓主工作区交互整合（2026-11-23）

## 交互目标

以会话为工作中心：侧栏直接切换历史会话；集中管理由弹层承担；审批在对话与顶栏入口复用同一请求卡片；本地终端始终以输出视窗为主体。

| 能力 | 交互位置 | 组件 |
| --- | --- | --- |
| 近期会话切换 | 侧栏 | SidebarSessions |
| 搜索、分组、归档、批量管理 | 管理弹层 | ThreadLibraryQuickSheet / ThreadLibraryPage |
| 当前任务审批与通用待决入口 | 对话/通用弹层 | ApprovalQuickSheet / ApprovalRequestCard |
| 本机审批记录 | 审批弹层折叠区 | ApprovalAuditSection |
| 本机命令执行与输出 | 终端工作区 | TerminalPage |

旧 threads、approvals 导航入口仍可由原调用方使用，Shell 将它们统一转为弹层；既有权限、搜索、PTY 与输出导出协议原样保留。

## 验收标准

1. 侧栏只保留对话、总览和文件等主要工作入口。近期会话可直接切换，“查看全部会话”打开管理弹层，可筛选、搜索、批量处理。返回键先关闭弹层。
2. 待审批时在当前对话或顶栏打开同一个审批组件，显示命令原文、文件变更和权限范围，审批记录可折叠查看。
3. 终端进入即显示可滚动的输出区域，输入区位于底部。风险确认、PTY、停止、历史、复制、分页与日志导出使用既有能力。
4. Android 35 393dp 回归覆盖侧栏、管理弹层、审批弹层、终端空状态和确认；补充 360dp、411dp、大字体和窄屏返回测试。

## Figma 同步规则

保留原有主题令牌；主界面采用会话抽屉与任务对话区。管理弹层占可用屏幕高度不超过约 92%，内容内部滚动；审批继续复用同一个卡片；终端以输出视窗占剩余空间，执行中扩大输出区域。减少内部字段说明和卡片堆叠。
