# 111 仓库工程文档导航

按**文件实际用途**归档：

- `architecture/`：整体架构、跨模块审计与执行路线。
- `conventions/`：命名与目录权威规范、历史迁移记录。
- `restoration/v40` 至 `v43/`：逐版本源码恢复、Daemon 生命周期及校验记录。
- `research/v37/`、`research/v44/`：历史源码对照、函数证据与候选复核。

原始内嵌文档保留在 `resources/docs/`；对应语言与主题分类已由 `resources/asset-layout.json` 维护。原始 BunFS 文件保留在 `resources/bunfs/`，不可随意重命名。功能源码在 `src/`；源码恢复、索引和运行入口在本轮未变更。
