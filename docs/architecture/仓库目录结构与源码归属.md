# 111 仓库目录结构与源码归属（2026-10-28）

> 本文仅记录当前整理分支已提交的目录归属和历史原件边界，不等同于业务功能恢复或等价验收。当前精确旧新路径以 `resources/layout/relocations.json` 为准；目录结构以 Git 树为准。

## 根目录职责

| 路径 | 内容与职责 | 目录属性 |
| --- | --- | --- |
| `src/` | 2.1.310 主程序的 2,551 个受检验模块（2,547 个 chunk、启动文件、原生模块装载适配文件，以及 Hook Worker）；另有三个原版预构建图表/高亮/流程图库 | 主程序源码，模块指纹与导入图不可随意重排 |
| `bin/` | `claude-310.mjs`，CLI 执行入口 | 可执行入口 |
| `runtime/` | BunFS 资源读取、Node/Bun 字符宽度运行兼容 | 运行时代码 |
| `embedded/` | 24 份独立提取的源码及配套配置；内部按运行时、组件、浏览器工具、设计模板、组件构建、Agent 指导分组 | 独立源码 |
| `plugin-testing-kit/` | 294 份插件测试辅助源码；按 collector、equality、mock、run 等实际模块职责保留目录 | 独立源码 |
| `tools/analysis/` | 调用图、函数影响分析、闭环审计与导出 | 工程源码/分析工具 |
| `tools/dev/` | 开发工具链、Bun/JSC 兼容诊断及探针 | 工程源码/构建工具 |
| `tools/bundled/` | 56 份原程序随包工具、类型、辅助模块和来源清单；按 claude-test、design-sync、plugin-api、evaluation 等子工程分组 | 随包工具源码 |
| `scripts/` | 安装、源码抽取、索引、候选核验、资源消费者与交付检查脚本 | 维护及验证脚本 |
| `tests/` | 实际回归测试；按 agents、cli、daemon、governance、hooks、mcp、model、plugins、restoration、runtime 分类；顶层保留公共检查入口、helpers、fixtures | 测试与辅助文件 |
| `docs/` | architecture 架构归属、conventions 规范、research 固定版研究、restoration 版本恢复记录、history 历史对照、reference 以外的工程文档 | 工程文档 |
| `resources/bunfs/` | 原始压缩/未解压资源及原生 .node、字体等；原虚拟文件名和 SHA 均保留 | 原版可追溯资产 |
| `resources/data/` | 内嵌数据（如 PSL、工具快照） | 数据 |
| `resources/docs/` | 70 份按 Claude API、语言与业务主题分类的参考文档 | 运行资源中的文档 |
| `resources/skills/` | 14 份按技能名称分类的 `SKILL.md` | 原版技能资源 |
| `resources/templates/` | 9 份 UI/制品 HTML、CSS 模板 | 原版模板资源 |
| `resources/research/` | 固定版历史证据、符号定位、语义验证清单；保留原固定文件名，不覆写历史证据 | 研究证据 |
| `resources/*.json` 与 `resources/layout/` | BunFS 重定位、源码指纹、函数账本、别名、消费者索引、准确的旧新路径映射 | 资源与证据元数据 |
| `.github/workflows/` | GitHub CI、交付门禁、开发工具链、跨版本源码检查 | 自动验收配置 |

根目录的 `README.md`、`AGENTS.md`、`package.json`、`package-lock.json`、`LICENSE`、`.gitignore` 均保留其标准位置。
